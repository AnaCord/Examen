### ¿Qué es PHP?
PHP es un lenguaje de programacion interpretado utilizado para el desarrollo web. Cabe destacar que tambien es
codigo abierto

###  ¿Para que nos sirve un Foreach?
 Un foreach es un ciclo que recorre cada linea.
 Donde itera en un arreglo, cada iteración, asigna el valor actual a la variable que se este utilizando.
 
###  PHP es un lenguaje de programación Compilado o Interpretado?
PHP es un lenguaje de programacion interpretado porque a la hora de ejecutar el codigo interpreta cada instrucion en el momento

###  Para qué nos serviría usar PHP?
Comunmente es utilizado para el desarrollo web.


### Para qué nos sirve el IF en php?
Es una condicional que nos permite elegir entre 2 o mas opciones. Donde si una opcion no se cumple
se asigna el siguiente.
